# Versión estudiante

## Instrucciones
Ejecuta la aplicación y entra a `http://localhost:8080`.

Cada ejercicio contiene una pregunta o un error intencional. No revises la versión `solution` hasta terminar.

### Ejercicio 1
Compara `@RequestParam` con Data Binding. Luego intenta agregar el campo `correo`.

### Ejercicio 2
El formulario tiene un `name` incorrecto. Antes de modificarlo:
1. Predice qué atributo llegará como `null`.
2. Envía el formulario.
3. Corrige el error.

### Ejercicio 3
Antes de enviar, predice el objeto final. Luego elimina temporalmente el campo `edad` del HTML y observa qué ocurre.

### Ejercicio 4
Hay dos campos cuyo `name` no coincide con el Bean. Encuéntralos y corrígelos.

### Ejercicio 5
Prueba:
- no enviar `managerId`;
- enviar `managerId` vacío;
- cambiar `Integer` por `int`.

Explica la diferencia observada.
